# Homebrew tap for Hey Mac

```sh
brew install --cask iharshitmaurya/tap/heymac
```

Or add the tap first, then use the short name:

```sh
brew tap iharshitmaurya/tap
brew install --cask heymac
```

Remove it with `brew uninstall --cask heymac`, or `brew uninstall --zap --cask heymac` to also delete its data folder, preferences and log. The in-app **Settings → About → Uninstall** removes everything, including the Keychain key.

Hey Mac itself lives at https://github.com/iharshitmaurya/HeyMac.
